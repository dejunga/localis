# Završni upitnik za polaznike — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Javni upitnik `/upitnik/[slug]` za svaku edukaciju iz `lib/edukacije.ts`, automatski mail kontakt osobama prijava nakon edukacije i tab "Upitnici" u adminu s odgovorima, QR kodom i Excel exportom.

**Architecture:** Čiste funkcije u `lib/upitnici/*` (rokovi, validacija, odabir primatelja, sažetak, Excel) s vitest testovima. Javna stranica + server action po uzoru na prijave. Vercel cron (Hobby, jednom dnevno) zove `app/api/cron/upitnici/route.ts`. Admin stranice pod `app/admin/upitnici/`.

**Tech Stack:** Next.js 16 App Router, Drizzle + Neon Postgres, nodemailer (Zoho), `exceljs`, nova ovisnost `qrcode`, vitest.

**Spec:** `docs/superpowers/specs/2026-10-29-upitnici-design.md`

## Global Constraints

- Prije pisanja Next.js koda pročitati relevantni vodič u `node_modules/next/dist/docs/` (AGENTS.md) - posebno route handlers, server actions, `params` kao Promise.
- Sva vremena po `Europe/Zagreb`. Otvaranje = početak iz `seminar.time`; rok = kraj iz `seminar.time` + 96 h, osim ako je zadan `upitnikRokDo`.
- Neparsabilan `time`: početak = 00:00, kraj = 23:59 na `seminar.date`.
- Upitnik postoji samo za edukacije koje vraća `getSeminar(slug)` (bez skrivenih) i nisu `odgodeno`.
- Obavezno: ocjena ukupno, ocjena svakog predavača, ocjena korisnosti (cijeli broj 1-5). Sve ostalo opcionalno.
- Email kontakta u upitniku zahtijeva privolu; bilježi se `UPITNIK_PRIVOLA_VERZIJA`.
- Mail ide samo kontakt osobi ne-stornirane prijave, jedan po (edukacija, email bez obzira na velika/mala slova). At-most-once.
- Cron: `vercel.json` `"schedule": "0 17 * * *"`, zaštita `Authorization: Bearer ${CRON_SECRET}`.
- Rate-limit javne forme: ključ `upitnik-ip:<slug>:<hashiraniIp>`, max 60 / 60 min.
- `noindex` za `/upitnik/*`, ne ide u `sitemap.ts`.
- Tekstovi korisniku na hrvatskom; commit poruke na engleskom u stilu povijesti ("Add ...").
- Ne pokretati `npm run db:migrate` na produkcijsku bazu, ne postavljati Vercel env i ne deployati bez potvrde korisnika.

## Review Focus

1. **Edukacija tik nakon promjene sata** (izvlaštenje 28.10.2026., zimsko vrijeme od 25.10.) - kraj i rok moraju biti točni u UTC (15:30 CET = 14:30Z). Test u Task 1.
2. **Edukacija bez predavača ili s više njih** - skala po predavaču; 0 predavača = pitanje se ne prikazuje i nije obavezno. Test u Task 3.
3. **Ista email adresa na dvije prijave, različita velika/mala slova** - jedan mail. Test u Task 5.
4. **Cron pokrenut dvaput istog dana** (ručno iz Vercel dashboarda) - nema drugog maila; red bez `poslan_at` i bez `greska` ne šalje se ponovno. Test u Task 5.
5. **Email kontakta upisan bez privole / privola bez emaila** - prvo je greška, drugo se ignorira (privola se ne bilježi). Test u Task 3.

- [ ] **Step 3: Implement** u `lib/upitnici/rok.ts`. Iz `time`: početak = prvo `H.MM`/`H:MM`, kraj = drugo (iza `-`); ima početak a nema kraja -> kraj 23:59. Pretvorba zagrebačkog lokalnog vremena u `Date`:

```ts
// Zagreb lokalno -> UTC: pogodi kao UTC, izmjeri offset Zagreba u tom trenutku, oduzmi.
function zagrebUDate(datum: string, sat: number, minuta: number): Date {
  const [y, m, d] = datum.split("-").map(Number);
  const guess = Date.UTC(y, m - 1, d, sat, minuta);
  const p = Object.fromEntries(new Intl.DateTimeFormat("en-US", { timeZone: "Europe/Zagreb",
    year: "numeric", month: "2-digit", day: "2-digit", hour: "2-digit", minute: "2-digit", hourCycle: "h23" })
    .formatToParts(new Date(guess)).map((x) => [x.type, Number(x.value)]));
  const offset = Date.UTC(p.year, p.month - 1, p.day, p.hour, p.minute) - guess;
  return new Date(guess - offset);
}
```
